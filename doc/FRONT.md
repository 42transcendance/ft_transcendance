## Front-end

### [Nuxt (including View)](https://nuxt.com)
Page management and global project architecture. Allows in particular to create reusable components (buttons, navbar, etc.).

### [three.js](https://threejs.org)
3D animation on the index. 

### [Tailwind CSS](https://tailwindcss.com)
CSS framework that allows you to directly define the style in the "class" tags of the components. Creates a lot of redundant code, not necessarily suitable for Nuxt.

### [lil-gui](https://lil-gui.georgealways.com)
Adds controllers to the page, in order to graphically adjust selected elements without having to modify the code.

### [GSAP](https://gsap.com)
Tool to make advanced JS animations, while maintaining accessibility and performance.
