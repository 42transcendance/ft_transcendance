# 42_pixel_fight

## Pour lancer le test

Lancer le serveur en local :
`npx serve .`

Et le serveur qui héberge la partie :
`npx tsx src/server.ts`

Puis lancer le compilateur :
`npx tsc --watch`

ici `--watch`
Permet de track les erreurs de compilations en temps reel.

Puis se rendre sur la page :
`localhost:3000`
